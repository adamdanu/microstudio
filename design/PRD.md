## Problem
Adobe Stock contributors hand-write titles, keywords, and categories for every photo. Poor metadata = poor discoverability = fewer sales. Writing it by hand is slow and inconsistent.

## Target user
Adobe Stock contributors who want SEO-optimized, submission-ready metadata in seconds from a single image drop.

## Goal
Drop an image → get Adobe-Stock-ready **title**, **ordered keywords**, and **category** in one click, using a world-class SEO eye (10-year Adobe Stock experience).

## Core user flow
1. **Upload** — drag & drop or paste an image; preview appears.
2. **Analyze (auto on drop)** — vision model describes the image.
3. **Generate metadata** — SEO-expert step produces:
   - **Title**: short, factual, descriptive sentence, **≤ 70 characters**, no brand/camera names.
   - **Keywords**: **15–35** relevant keywords, **most important first** (first 10 carry extra search weight).
   - **Category**: best match from Adobe's **official 21 categories**.
4. **Output panel** — title with live char counter, keyword chips (reorder/remove/add), category dropdown (preselected suggestion).
5. **Export** — copy title, copy keywords, copy all (CSV-ready: filename,title,keywords,category).

## Requirements

### Functional
| ID | Requirement |
|---|---|
| F1 | Drag-drop + paste image upload (local, no server storage) |
| F2 | Multi-provider vision/LLM: **Gemini**, **OpenAI**, **Anthropic** (user's own API key, stored locally) |
| F3 | Title output ≤ 70 chars, generated by SEO persona |
| F4 | 15–35 keywords, importance-ordered (first 10 = highest weight) |
| F5 | Category chosen from Adobe's official 21-category list |
| F6 | Output editable (title field, keyword chips reorder/add/remove, category dropdown) |
| F7 | Copy buttons: title, keywords, all-as-CSV |
| F8 | Session history of past analyses |

### Non-functional
- Standalone local Next.js app (no deploy required) — runs on Mac `localhost`
- API keys stored locally (browser localStorage or local env), never sent to a server we don't control
- Single file drop = single analysis round; response < 15s

## Adobe SEO rules embedded (the "10-year expert" persona)
- Title: conversational, factual, descriptive, <70 chars, camera/brand names prohibited.
- Keywords: 15–35, specificity first; first 10 carry extra weight; no irrelevant/duplicate keywords (rejection risk).
- Category: most specific match; closest if none perfect.
